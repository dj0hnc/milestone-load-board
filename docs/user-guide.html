💡 The 30-second mental model
Open the app → it connects and loads today by itself → you plan trucks onto orders (drag, type, paste from Excel, or let ⚡ Auto-plan do it) → hit Finalize on each ready order → press ⟳ Push to NewMile (or just wait — the next refresh writes it for you). Everything else in this guide is power tools around that loop.

1Install — Windows & Mac

🪟 Windows

1
Get MilestoneLoadBoard-2.1.1-portable.exe from the company SharePoint / Teams link.
2
Copy it anywhere — Desktop, Documents, even a USB stick. It is a single portable file: no installer, no admin rights.
3
Double-click it. The very first launch takes ~10 seconds (it unpacks itself). After that it opens fast.
⚠ "Windows protected your PC"
If Windows SmartScreen appears the first time (normal for internal tools), click More info → Run anyway. You will never see it again.

🍎 Mac

1
Get MilestoneLoadBoard-2.1.1.dmg (works on Apple Silicon and Intel).
2
Open the .dmg and drag the app to Applications.
3
First time only: right-click the app → Open → Open (the app is internally distributed, not App-Store signed). After that it opens normally.
⚠ If macOS still blocks it
Open Terminal and run:
xattr -cr /Applications/MilestoneLoadBoard.app

Updating to a new version

When a new version is published, the app shows a green ⬇ Update v2.x.x button in the title bar. Click it — the new file downloads to your Downloads folder. Close the app and run the new file. Your login, settings and history are kept automatically (they live in your user profile, not in the file).

Manual route: replace your old .exe / .app with the new one from SharePoint. Same result.

Reading an order card

✓ En NewMile Ed Bell #57 · 04:00 #57 Limestone · Ed Bell Construction MM Celina Rail → Webber WOK US-380 🗺 🕖 4:00 AM ~32 mi · ~43 min 📝 2 1,000 t Ordered | 463 t Delivered · live | 9 Loads to add 12 trucks · NewMile · loads in 18

Day navigation

The ‹ › arrows move between yesterday (real actuals — trucks, loads, tons as they happened), today (live) and tomorrow (what's already in NewMile — keep assigning to it). All three days carry full real assignments.

5Planning

The Planner tray

Click an order (or select several, or press 📋 All orders) — the Excel-style tray opens on top: one row per order with TRK / LDS cells, live group tallies (WW·RHO·POW·CAC·AGG·SUB) and totals. Type truck numbers, drag trucks in, or paste from Excel. Drag the gold handle to resize; ⬇ Export plan still produces the plan_DATE.json if you ever need the file.

📋 Paste straight from Excel

Copy your cells in Excel, click any TRK box, press Ctrl+V (Cmd+V on Mac). The grid grows automatically if you paste more trucks than there are boxes.

Accepted formats — all auto-detected
Horizontal pairs (the dispatch-sheet layout): 1109 | 4 | 1123 | 4 | 1082 | 4 … → each truck gets its loads.
Trucks only: 1117 | 2012 | 351 → trucks pasted, LDS left empty (never invented).
Vertical two columns: truck in A, loads in B.
Rule: a pure 1–2 digit number right after a truck = its load limit. Everything else (3+ digits, KT-…, letters) = a truck.

⚡ Smart Dispatch panel (bottom-right)

ControlWhat it does
⚡ Auto-plan Alt+AFills every uncovered selected order (or all uncovered) with trucks. Rotation is law: rested trucks first, always. Among equally-rested candidates it prefers the one parked closest to the pickup (live Samsara GPS) — and picks randomly among equivalents, so the same trucks don't get the good runs every day.
🎲 Re-rollDeal a different valid plan — same fairness, new combination. Keeps anything already live in NewMile.
⚙ Plan filtersConstrain the pool: include/exclude fleet groups, max deadhead miles, GPS-only, on-call-only, fixed loads-per-truck. Remembered.
Options — (order)Focus an order and the panel offers 3 alternative truck sets with average deadhead — click Use to apply one to just that order.
KPIsProjected fulfillment, trucks/tons planned, orders still short, rested trucks idle, avg deadhead of the last auto-plan.
Rule checksLive validation before you push: missing load limits, ATX Bluewing, no-driver trucks, duplicates across orders, EYK/Watercrest rate flag, trucks parked >75 mi from pickup.
Repeated truck #Some numbers belong to two different trucks (1387 is an Alanis truck and a Cactus truck). Type one and the board asks which one before it lands — pick once and it sticks for the session, with the owner shown on the planner chip (tap the tag to change it). The push then carries that truck's NewMile id, so it can never land on the other owner. Trucks dragged from the rail or picked by Auto-plan never ask.

6Pushing to NewMile

The one mental model

1
Plan trucks onto an order (any method from §5).
2
Press Finalize on the order card → it is queued for NewMile.
3
Either press ⟳ Push to NewMile to write it now (preview first), or do nothing — the next refresh (manual or auto) writes the queue automatically, then pulls the fresh truth back.

The Push preview

Every order shows its trucks, loads and rate badges. Push orders one by one or Confirm & push all. Results per order:

✓ +3 new · ~1 updated · 4 untouched
  • new — created and confirmed in NewMile (drivers see them).
  • updated — truck was already on the order with a different load limit → only the limit was changed.
  • untouched — already there, identical. The app never re-writes or disturbs existing assignments.

Safety rules — enforced automatically, every time

RuleDetail
Rate blockcontracted_rate · driver pay 0 · custom · Ton — on every assignment.
EYK / WatercrestAuto-detected → order_default rates instead.
ATX BluewingNever assigned. Filtered everywhere.
Neversend_offer · close_order. Orders staying pending in NewMile is normal and correct.
IdempotentPushing twice changes nothing the second time.
💡 Where did my order go?
If an order disappears from view after finalizing, it's a filter: it just became covered and you have the "needing loads ▸" view on. The toast tells you when this happens. Your work is never lost — refreshes preserve your selection, drafts and the day you're viewing.

7Live Alerts

The right column watches the day for you. Click any alert to jump to its order. Hover → ✕ dismisses it for the day ("checked"); Clear all wipes the current list (new ones still come in). The whole panel collapses with ▾.

AlertFires when
🛰 Not movingAfter your set hour: a truck is assigned today, has no load started in NewMile, and Samsara GPS shows it sitting still. Call the driver or rotate a backup in.
🚨 NOT STARTEDAfter your set hour: an order has material due and zero loads hauled. The text says whether trucks are assigned ("find out why nothing is moving") or not ("cover it now").
🐌 only X% doneOrder started but is below your % watermark.
🚩 ShortOrder not fully covered — shows loads still needed.
⛔ No-showTruck marked no-show in AM Check.
✎ Re-finalizePlan edited after finalizing — queue it again.
🔄 Idle trucksFair-rotation reminder.

All thresholds (hours, %, minutes) live in ⚙ Settings under the alerts — see §14.

8🗺 Live Map

Click 🗺 Map any time — it opens on demand (never in your way).

  • Search any truck by number or driver → the map jumps to its live Samsara position. Green = moving (with mph) · amber = parked.
  • The popup shows driver, phone (click-to-call), speed and GPS time.
  • 📷 Dashcam snapshot — requests a live road-facing photo from the truck's camera. Takes 30–60 s (the cam uploads on demand); the window updates alone. Works while the truck is running.
  • ✉ Message — opens the composer pre-addressed to that driver (§9).
  • If an order is focused in the planner, its run (pickup → dropoff) is drawn on the map too.

9💬 Messages

NewMile messaging, inside the app

The 💬 tab embeds the real NewMile messaging page. First time: you may see the NewMile sign-in there — log in once, it sticks forever (separate from the main connection).

  • Unread badge on the 💬 tab + a chime when a new driver message arrives.
  • Repeating reminder every N seconds (you choose, §14) until you open the tab or the count hits zero — no more missed drivers.
  • 🌐 Translator — Spanish messages get a subtle blue "→ English" line underneath, automatically. Toggle it with the 🌐 checkbox; it changes nothing in NewMile itself.

✉ The message composer

Open it from a map pin, from 🚛 Truck Manager (select trucks → ✉ Message), or 💬 → ✉ New message. Pick a template, pick the language, and the merge fields fill per driver from live data:

Template (Español · Dispatch tomorrow): "Hola {driver}, mañana cargas en {pickup} — {material} para {order}. Inicio {time}, {loads} carga(s). Confirma por favor. 🚛" Resolved for truck 1117: "Hola Jacob, mañana cargas en MM Celina Rail — #57 Limestone para Ed Bell #57. Inicio 4:00 AM, 4 carga(s). Confirma por favor. 🚛"
  • Templates: Dispatch tomorrow · Confirm rolling · Where are you · Custom — English and Spanish. Fully editable before sending.
  • Mass-send: select 15 trucks in Truck Manager → each driver gets his own personalized text. Preview lists every recipient first; the Send button requires a second confirming click.
  • Delivery goes to each driver's Samsara app (matched by phone). Rows marked no match get a 📋 copy button instead — paste into NewMile chat manually.
  • Per-row result: ✓ delivered or ✗ with the reason.

ActionWhat happens

12💰 Load Quoter

Price any run in a minute, with real road miles and drive time — not guesses.

1
Route: type pickup & dropoff (known yards autocomplete; any full address works) → 🛣 Get miles & time. Or click ⤵ Use focused order to prefill from the board.
2
Job: $/ton, $/yard, $/load or $/hour, rate, FSC %, quantity, truck capacity.
3
Costs: MPG, diesel, driver %, wait/load/unload minutes, workday hours, tolls, NewMile fee, weekly opex. All values stick — set them once.
4
🧮 Quote it.

13Reports — PM Assigned & AM Rolling

Both buttons live in the summary strip. 📋 PM Assigned is the night report (what got assigned); 🌅 AM Rolling is the morning check (assigned vs actually rolling — rolling is live from NewMile, no manual tapping needed). Both break the fleet into the real groups and copy to clipboard with one click:

TRUCKS ASSIGNED: 138 KT — Kennemer (6): 46 CE — Cactus (5): 57 AGGSHIP + CT: 12 CKJ Subs: 14 Other Subs: 9

Sub grouping uses owner rules (e.g. "… - CKJ" owners). A misfiled sub? It's a one-line fix in newmile.config.json → groups → owner_overrides.
